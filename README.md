# New-Hire-Dashboard
[🚀 View the Live Dashboard](https://new-hire-dashboard-c4qfjpewfvnmneunhttcrw.streamlit.app/)

New hire dashboard that shows expected production forecasted for the week vs. actual production. With a coaching report to give trainers easy-to-read highlights. This is based on a standardized 6-month new hire retention curve for production and milestones.

# Performance Classification

Employee performance is classified using the following thresholds:

🟢 Meeting Target
- Performance is at or above the target

🟡 Caution
- Performance is 5–9.9% below target

🔴 Warning
- Performance is 10% or more below target
